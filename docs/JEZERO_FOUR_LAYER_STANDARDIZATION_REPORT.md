## Hillshade algorithm and assets

Reproduce from the repository root with Python/numpy/rasterio/Pillow:

```powershell
python team/jezero/terrain/build_hillshade.py team/jezero/terrain/source/jezero-dtm.tif public/maps/jezero/hillshade-tiles --report team/jezero/terrain/hillshade_report.json
python -m unittest discover -s team/jezero/terrain -p test_hillshade.py -v
python team/jezero/terrain/validate_real_hillshade.py
python team/jezero/terrain/inventory_assets.py
npx.cmd tsx --test tests/jezero-four-layers.test.ts
```

The generator fails closed on unexpected raster dimensions, CRS, sphere, affine, numeric type or strip layout. Pixel centers are used explicitly (`affine-inverse - 0.5`), rather than copying the legacy half-post indexing error. For every global XYZ display pixel center it bilinearly samples actual DEM elevations at the center and cardinal ±1 native-map-post positions. Every contributing post must be finite and non-nodata. No center substitution, extrapolation, invented elevations or gap filling occurs.

`dz/de = (east-west)/(2*1m*cos(latitude))`; `dz/dn = (north-south)/(2*1m)`. This accounts for equirectangular latTs=0 east/west map scale. The native cardinal baseline is 2 map metres (east ground baseline approximately 1.897m at Jezero); bilinear interpolation adds support around the queried samples. No native-post slope precision is claimed for legacy display-grid slope.

The local surface normal is proportional to `[-dz/de,-dz/dn,1]`. Artificial light has azimuth **315° clockwise from north**, elevation **45°**. Intensity is `clamp(dot(unit normal, unit light),0,1)`. Flat ground is `sin(45°)=0.7071`, quantized to gray 180. Output is neutral grayscale `round(255*intensity)` with valid alpha 255 and unsupported pixels RGBA zero. There is no gamma, ambient light, contrast stretch, cast-shadow model, smoothing, elevation correction or geometry warp. Illumination is a visualization parameter, not an observed solar condition.

Outputs: `public/maps/jezero/hillshade-tiles/{z}/{x}/{y}.png`, XYZ 256px RGBA at zooms 5–14, full native DEM envelope plus transparent western mission-tile padding. Report includes exact tile count/ranges, PNG hashes, source hash, software versions, source WKT, affine and parameters. Independent geographic registration remains UNVERIFIED. Coarse zooms sample fine relief without anti-alias averaging, so aliasing is a stated display limitation. Strict derivative support erodes nodata boundaries and can eliminate narrow valid islands rather than fabricating relief.

`dem-valid-footprint.geojson` traces the actual full-resolution native mask. Four `*-display-footprint.geojson` files trace actual nonzero-alpha cells at each layer's highest stored zoom, separated by tile; other zooms retain their own PNG masks. These are Mars/display coordinates, not Earth distance geometry. The native mask is not presented as an exact hillshade derivative mask; actual derivative validity is PNG alpha.
